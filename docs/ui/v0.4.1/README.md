# ToolDeck v0.4.1 界面设计规范与功能矩阵

本目录中的 18 张 PNG 是 v0.4.1 的视觉与交互基准。全部页面只能沿用用户最初提供的参考图所定义的窗口结构、石墨色阶、青蓝强调、控件尺寸、表格密度、线性图标和空间节奏，不允许页面间出现其他风格。首页稿只负责固化同源应用外壳，不能替代最初参考图的主基准地位；`18-unified-navigation.png` 是后续确认的全局导航修订稿，其单列导航覆盖 01–17 中出现的旧双栏导航。设计图不是运行时资源；实现应使用 egui 原生布局、绘制和文本组件还原。若生成图中出现本矩阵未列出的控件、文字或工具，该内容视为生成瑕疵，不进入实现。

## 统一外壳与视觉令牌

- 保留 Windows 系统标题栏。应用内依次为 48pt 顶部栏、236pt 单列统一侧栏和主工作区，不再同时显示分类栏与工具栏。
- 分类固定为“诊断、网络、通信”；工具 ID 与现有命令行入口保持不变。
- 统一侧栏顶部使用“诊断、网络、通信”三个分类标签，下面只显示当前分类工具；980px 宽度下同一侧栏收起为 72pt 图标态，点击分类后在原位置展开。
- 背景使用石墨黑层级，主强调色为青蓝色；发送为绿色、接收为蓝色、危险操作为红色。
- 控件高度 32–34pt，表格行高 38–40pt，圆角 4–6px，边框 1px。仅主要操作使用实色按钮。
- 中文正文优先“Microsoft YaHei UI”；地址、时间、数字和载荷优先“Cascadia Mono”，回退到“Consolas”。
- 不使用 Emoji 或字符图标。分类、工具与操作图标全部使用统一线宽的矢量图形。
- 只有深色主题；旧设置中的 `theme` 字段仅兼容读取，不再提供主题切换。

## 状态、数据与隐私边界

- 持续与周期任务必须显示运行状态和停止入口；同类周期任务不得重叠提交。
- 页面切换后通信会话继续运行；旧请求或旧 generation 的结果不得写入新会话。
- 所有破坏性进程操作必须二次确认。错误信息放在对应操作区附近，并保留可复制的诊断内容。
- 预设只允许保存协议模式、地址族、超时、间隔、次数、显示格式、CRLF、日志过滤和串口格式等非敏感枚举或数值。
- 目标、域名、路径、PID、通信端点、载荷、日志、最近系统结果和用户实际地址只存在于当前进程内存。

## 图片审阅规则

每张图必须满足：外壳与首页锚点一致；只出现本矩阵规定的工具和控件；中文清晰无乱码；无文字重叠、裁切、方块字、随机按钮、HTTP/WebSocket/SSE 等未规划工具；表格、日志和趋势区域获得主要高度。
