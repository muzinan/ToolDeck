# ToolDeck v0.3.1

本版本对 ToolDeck 的整体界面进行了系统性升级，重新设计了主页、导航、主题和各诊断工具的结果展示。新版更突出关键指标与运行状态，在宽屏、高密度工具列表和深浅色主题下都能更快定位信息，同时保持原有诊断能力和使用方式不变。

## 重点更新

### 全新科技工作台

- 新增顶部 HUD 状态栏，集中展示当前位置、运行状态、收藏入口和主题快捷切换。
- 主页增加工具总数、收藏数、最近运行和诊断引擎状态等概览指标，并支持按全部、收藏及工具分类快速筛选。
- 新增网格卡片与紧凑列表两种浏览模式，兼顾图形化浏览和大量工具的高密度扫描。
- 侧边栏升级为带实时数量的分类折叠导航，并保留全局搜索与收藏快捷入口。

### 统一诊断结果视觉层级

- 文件占用、端口检查、进程关系、DNS、Ping、TCP 和 MTR 页面统一采用重点卡片、指标磁贴与状态徽章。
- MTR 结果区域新增轮数、已发现跳点和探测状态概览，路径表格与运行状态更加醒目。
- DNS、Ping、TCP、端口和进程结果增加关键统计摘要，减少在明细中查找核心数据的时间。

### 深浅色主题与图标升级

- 重新调整深色与浅色主题的背景、边框、强调色、成功、警告和错误状态配色。
- 为 DNS、Ping、TCP 和 MTR 绘制独立矢量图标，提升不同网络工具的辨识度。
- 增加 Windows 符号与表情字体回退，改善星标、箭头、状态符号和主题图标的显示兼容性。
- 主内容区最大宽度由 1040px 扩展至 1600px，更充分利用宽屏空间和多列表格。

## 修复与改进

- 优化卡片、按钮、徽章和输入控件的间距、圆角、边框与悬停反馈。
- 改善侧边栏分类较多时的滚动和折叠体验，并显示各分类的工具数量。
- 统一各工具页标题、说明、空状态、运行状态和错误状态的表达方式。
- 应用内版本徽章改为自动读取 Cargo 包版本，避免发布时界面版本遗漏更新。

## 升级说明

- 支持 Windows 10/11 x64，系统要求与上一版本一致。
- 不涉及配置迁移或额外授权，可直接覆盖升级。
- 原有收藏、主题和工具设置继续沿用。
