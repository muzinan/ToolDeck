# ToolDeck v0.4.0

本版本新增 TCP、UDP 与串口三个独立通信调试工具，让 ToolDeck 从一次性网络诊断扩展到可持续收发的通信工作台。三个工具统一支持文本/HEX、定时发送、有界记录和手动导出，同时保持现有 TCP 端口快速测试、Ping、MTR 与命令行协议兼容。

## 重点更新

### TCP 通信调试

- 新增 TCP 客户端与服务端模式，支持 IPv4、IPv6 和 100–30000 ms 连接超时。
- 服务端最多同时接入 32 个客户端，可向选中客户端或全部客户端发送原始 TCP 字节流。
- 正确处理 TCP 流式分段、部分写入和每连接 1 MiB 待写上限；本工具不进行 TLS 封装。

### UDP 通信调试

- 支持配置本地绑定与默认远端，覆盖 IPv4/IPv6 单播和 IPv4 广播，并保留每个数据报的来源信息。
- 可直接回复选中的接收来源，单次载荷限制为 UDP 有效上限 65507 字节。
- 新增单个 IPv4 组播组配置，可选择本地 IPv4 接口、TTL 和本机回环；IPv6 广播与组播不属于当前版本范围。

### 串口通信调试

- 使用 serialport 4.x 枚举并独占打开 COM 口，展示可用的 USB 厂商、产品、序列号和 VID/PID 描述。
- 支持波特率、数据位、校验位、停止位、流控和 10–1000 ms 读取超时，默认使用 115200、8N1、无流控和 50 ms。
- 设备拔出、关闭或读写失败会留下明确状态记录、停止定时发送，并要求用户手动重连。

## 通用收发与记录

- 发送和接收格式可分别选择 UTF-8 文本或 HEX；发送可追加 CRLF，HEX 输入要求使用空白分隔的完整两位字节。
- 支持手动发送和 10–3600000 ms 周期发送；定时启动时立即发送一次，断线后自动停止。
- 主记录区按窗口高度约 58% 展示，支持方向过滤、暂停自动滚动、清空、复制和导出 UTF-8 `.log`。
- 每个工具最多保留 10,000 条记录和 16 MiB 原始载荷；超过上限淘汰最旧记录，队列拥塞丢弃数独立显示。
- 页面切换后会话继续运行；连接参数、载荷和记录不会自动保存，退出应用时关闭全部通信资源。

## 架构与兼容性

- 新增应用级持久通信 Dispatcher，为每个活动工具分配专用会话线程，并使用容量 64 的命令与事件队列提供背压。
- 收发记录按最多 128 条或 50 ms 批量返回，generation 隔离确保旧会话的迟到数据不会进入新会话。
- 原有固定四线程 Worker 只新增串口列表枚举，持续通信不会占用短任务执行槽位。
- 现有 `tcp-probe`、Ping、MTR、跨工具快捷入口和命令行参数保持不变；三个新工具不新增命令行入口。

## 升级说明

- 支持 Windows 10/11 x64，系统和架构要求不变，可直接覆盖升级。
- TCP 调试不支持 TLS；UDP 当前不支持 IPv6 广播与 IPv6 组播。
- 串口使用独占方式打开；若端口被其他程序占用，需要先关闭占用程序再重试。
