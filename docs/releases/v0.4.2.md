# ToolDeck v0.4.2

## 版本摘要

本版本将左侧导航栏从原水平分类标签重构为纵向手风琴抽屉（Accordion / Drawer）布局，支持分类按需折叠与展开，并保持原生系统窗口标题、视觉令牌与全功能交互与参考图 100% 一致。

## 重点更新

- **纵向抽屉式导航栏**：
  - 彻底替换旧版横向 `[诊断] [网络] [通信]` 分段按钮，改为纵向排列的抽屉手风琴列表。
  - 每个分类标题行具备展开/折叠指示箭头（展开 `∧`、收起 `∨`），点击分类可自由展开或收起子工具。
  - 当前活动工具所在分类默认保持展开；各分类可独立切换展开状态。
  - 子工具条目采用标准缩进排版，选中项在最左侧边缘显示 3px 宽青蓝强调色指示条（`#26B7E8`），选中项文字高亮强调，悬停具备微弱底色。
  - 顶部常驻“首页”入口，底部常驻“设置”入口，搜索模式下保留快速结果定位。
- **版本号与外壳规范**：
  - 更新版本号为 `0.4.2`，同步 Windows 应用清单、原生主窗口标题栏、构建与关于界面。
- **全页面与参考图一致**：
  - 首页、文件占用、端口占用、进程关系、DNS 查询、Ping、TCP 端口测试、MTR、TCP 调试、UDP 调试、串口调试、设置与关于各页面的视觉呈现、数据流和交互功能完全遵循参考设计图。
- **通信文字与报文可读性**：
  - 文本收发记录保留中文、符号和表情，发送记录固定使用发送时的文本/HEX 模式，接收记录跟随当前接收显示模式。
  - 自动滚动按钮明确显示运行或暂停状态；报文详情提供独立滚动内容区、复制操作和始终可见的底部按钮。
  - 长字段支持实际溢出时的全文悬停查看，通信日志、搜索、复制和导出保持同一显示规则。
- **紧凑布局与高分屏适配**：
  - 统一收紧控件、导航、卡片和表格行高，保留原有侧栏、控件顺序和宽屏布局。
  - 参数组在窄宽度下按完整标签与控件换行，长地址、IPv6、域名、路径和端点仅在自身控件或表格滚动区内滚动。
  - 文件占用、进程关系、端口占用、DNS、Ping、TCP 端口测试、MTR 及 TCP/UDP/串口调试页面统一采用内部双向滚动，避免页面横向撑宽。

## 升级说明

可直接覆盖安装或运行。收藏、最近访问工具、非敏感预设及系统参数兼容沿用。
