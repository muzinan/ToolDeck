# ToolDeck v0.4.1

## 版本摘要

本版本将 ToolDeck 重构为统一的深色专业工作台，并在保持十个工具 ID、命令行调用和核心任务边界兼容的前提下，补齐持续诊断、重复探测、结果筛选、通信控制和非敏感预设能力。

## 重点更新

- 应用外壳调整为顶部全局栏、236pt 单列统一侧栏和主工作区，工具统一归入“诊断、网络、通信”三类，删除重复的分类导航列。
- 仅保留石墨深色主题，使用青蓝交互强调、绿色发送状态、蓝色接收状态和红色危险操作；旧设置中的主题字段仍可读取。
- 980px 紧凑宽度下将同一侧栏收起为 72pt 图标态，点击分类后在原位置展开，不形成双栏或遮挡主操作区。
- 中文正文优先使用 Microsoft YaHei UI；地址、时间、数字和载荷优先使用 Cascadia Mono，并回退到 Consolas。

## 诊断工具

- 文件占用增加当前会话最近路径、结果过滤、手动或定时刷新、进程跳转、复制、文件定位和带确认的结束进程入口。
- 端口占用增加组合过滤、统计信息、列排序、暂停、1/2/5/10 秒刷新和 CSV 导出。
- 进程关系继续提供进程树、父链、子进程、路径、启动时间、按需读取命令行和带确认的结束操作。

## 网络工具

- DNS 查询增加周期运行、查询耗时、结果过滤、复制、导出和当前会话历史，并继续使用 Windows 系统 DNS。
- Ping 增加有限与持续模式、探测间隔、停止操作、逐包实时结果和动态丢包/延迟统计；探测语义仍为纯 ICMP。
- TCP 端口测试增加地址族、尝试次数、间隔、停止操作和逐次握手状态；仍为原始 TCP，不包含 TLS。
- MTR 增加每跳抖动、迷你趋势、复制和导出，同时保持真实重复节点及各 TTL 独立聚合。

## 通信工具

- TCP 客户端增加自动重连与重连间隔；服务端继续支持最多 32 个客户端及全部或指定客户端发送。
- UDP 保留 IPv4/IPv6 单播、IPv4 广播、单个 IPv4 组播组、来源选择和回复能力。
- 串口增加 RTS/DTR 手动控制；设备断开或读写失败仍会记录明确状态并停止定时发送。
- 三类通信页统一增加日志文本搜索，保留方向过滤、暂停滚动、清空、复制、导出、文本/HEX、CRLF、周期发送和字节统计。

## 设置与隐私

- 设置页新增非敏感参数预设，只保存工具类型、地址族、超时、间隔、次数、显示格式、CRLF 和串口格式等白名单字段。
- 目标、域名、路径、PID、通信端点、载荷、日志、查询结果和系统结果不会写入预设。
- 新增仅在 `ui-review` feature 下启用的界面截图入口；正式 Release 不包含该入口。

## 升级说明

可直接覆盖旧版本。窗口尺寸、收藏、最近工具和右键菜单设置继续沿用；旧主题设置会被兼容读取，但界面始终使用新的深色工作台主题。

## 验证范围

- 样式、导航、字体优先级、预设白名单、周期任务取消、重复探测、MTR 抖动和通信控制均包含自动化检查。
- Release 构建继续输出 Windows 可执行文件及 SHA-256 校验文件。
